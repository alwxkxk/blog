# 尚无上游发行修复的安全补丁

对应 GHSA-vfj7-8cjw-p6xm（braces）与 GHSA-hp3w-g68c-fv3c（sprintf-js）。2026-10-08 查询 npm，最新版仍分别为 3.0.3 和 1.1.3。

`dependencies.json` 保存原始文件 SHA-256、精确替换内容和补丁后 SHA-256。上游来源是锁文件所记录的 npm 官方包。包名、版本和许可证保持不变，`npm audit` 仍会如实报告上游受影响版本，不以改名或伪造版本绕过公告。

- **braces 3.0.3**：解析器限制实际语法嵌套深度为 128，涵盖花括号和圆括号；compile、expand、stringify 的递归入口也限制深度，保护直接传入 AST 的调用。转义和引号内的括号仍按文字处理。过深输入会提前抛出明确的 `SyntaxError`，不会继续递归到栈耗尽。
- **sprintf-js 1.1.3**：在格式串解析时限制宽度为 10,000、精度为 100，超限时在格式化参数或分配填充字符串前抛出 `RangeError`。普通翻译字符串、数字格式和转义百分号保留原行为。根 `overrides` 将旧插件里的 1.0.3 统一为同一个 1.1.3 补丁版本。

`npm ci` / `npm install` 的 `postinstall` 自动应用补丁；预览、测试、构建和 `npm run audit:security` 会检查已安装文件的补丁后哈希。源文件、版本或补丁上下文不符时失败，禁止静默跳过。不要用 `--ignore-scripts` 安装后直接绕过检查发布。

这些限制适用于本站构建输入，不能将无限宽度/精度或超深 AST 当作受支持功能。补丁不会把错误吞掉；调用者仍需处理无效输入。新增安全测试覆盖攻击样例与正常行为。

每次依赖更新时重新检查上游公告；有正式修复版本后，升级、删除相应补丁和审计例外，并执行全部测试及构建。不要只修改哈希使检查通过。
